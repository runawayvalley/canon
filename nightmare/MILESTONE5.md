# Milestone 5: Orchestration and sample-based render

Generated by `src/milestone5.py`, which builds on milestone 4, and `src/render_sf2.py`. Setup is in `README-render.md`.

Outputs:
- `midi/nightmare_canon_in_d.mid`: the final MIDI, 14 tracks, 4,769 notes (all present when re-parsed)
- `renders/nightmare_canon_in_d.mp3`: the full piece, ~6:15, 256 kbps
- `renders/nightmare_canon_in_d_climax_excerpt.mp3`: starts at cycle 29 (≈4:06)

## What changed vs. milestone 4

**Real instrument samples (GeneralUser GS).** Each track gets the matching General MIDI (GM) instrument:

| Track | GM preset | | Track | GM preset |
| --- | --- | --- | --- | --- |
| musicbox | 10 Music Box | | choir | 52 Concert Choir |
| celesta | 8 Celeste | | drone | 89 Warm Pad |
| violin1–3 | 40 Violin | | brass | 61 Brass Section |
| strings | 48 Fast Strings | | taiko | 116 Taiko Drum |
| pad | 49 Slow Strings | | bells | 14 Tubular Bells |
| cello | 42 Cello | | contrabass | 43 Double Bass |

**Orchestration additions:**
- **Tubular bell tolls** (an octave pair) mark each turn: cycle 9 (Canon Wakes), 17 (Descent), 25 (Fracture, on E♭), 31 (Climax), and 35 (the C# minor lurch). Each toll gets louder than the last.
- **Celesta** doubles the music-box melody an octave up in the Lullaby only. That makes the opening sweeter, so the later corruption hits harder.
- **Full string section** doubles all three canon violins through the Climax.

**Mix and master:**
- Each track is rendered as its own stem. Per-note detune (the drift and wobble) is applied with pitch bend.
- Each stem is auto-balanced to a target loudness for its role (see `LEVELS` in `milestone5.py`).
- The stems are panned and mixed, then processed in this order: tape-stops → reverb → hard cut (so the silence stays silent) → gentle soft limiter (peak about −1 dBFS).
